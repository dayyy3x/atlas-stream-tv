# ATLAS Stream TV

Android TV client for the **ATLAS Stream** media platform. A lightweight WebView / Trusted Web Activity app that loads the ATLAS Stream web player in a big-screen layout, so live TV, movies, and anime play on a television with a remote.

## Built with
* Java, Android (Gradle)
* WebView / TWA wrapping the ATLAS Stream web app
* Tuned for the onn Google TV and other Android TV devices

## What it does
* Launches straight into the TV-optimized player
* Streams live TV, movies, and anime from the ATLAS Stream backend
* Remote-friendly navigation on the big screen
